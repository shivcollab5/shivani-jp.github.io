Airline Passenger Satisfaction Analysis

Exploratory analysis of airline passengers to improve airline performance.

EDACustomer analyticsVisualisation

About the project

This project looks at how an airline serves both business and economy class passengers. Improving these services could grow the airline’s business, because customer satisfaction drives customer loyalty.

The analysis examines the factors behind positive and negative feedback and points to areas where the airline’s services can improve.

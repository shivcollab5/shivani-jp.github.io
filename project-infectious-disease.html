Infectious Disease Modelling

Simulating disease spread and control strategies with an SEIR compartmental model.

SEIREpidemiologySimulation

About the project

This project explores how infectious diseases spread and how well control strategies work, using the SEIR model.

It looks at how household size influences disease dynamics, and at the impact of increased diagnostic rates, case isolation and mass immunisation.

# Shivani Jeevan — Portfolio

This repository contains the static portfolio website for [shivani-jp.github.io](https://shivani-jp.github.io).

The homepage is `index.html`. Other pages and shared styles/scripts are in the repository root and `assets/`. The CV is served from `cv.pdf`, and profile and project images are in `images/`.
